Decisiones de arquitectura clave (registradas con fecha)

  • Roles: TECNICO, COORDINADOR, ADMIN. Solo el CRUD de usuarios (/users) está protegido por rol; Materiales e Inventory Movements siguen abiertos a cualquier usuario autenticado.
  • Valor unitario (011): entero en COP, opcional/nullable — no se asigna 0 automáticamente para distinguir "sin definir" de "vale cero". No se persiste snapshot histórico en cada movimiento.
  • Precios del checkpoint 015: son estimaciones de mercado colombiano (investigadas vía búsqueda web, julio 2026), no cotizaciones reales de proveedores — documentado explícitamente para no presentarse como dato verificado ante el profesor.
  • Sesión del frontend: cookie simple (no httpOnly) en vez de localStorage, necesario para que el middleware de rutas protegidas y los Server Components puedan leerla.
  • Inmutabilidad de movimientos: confirmado por especificación (RNF08) — no se pueden editar ni eliminar, por diseño.
  • Stock como entero: se difiere el soporte de decimales (kg, litros fraccionados).
